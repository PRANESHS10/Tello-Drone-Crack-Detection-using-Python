# Tello-Drone-Crack-Detection-using-Python
Dji Tello Drone  Wall Crack Detection using Python code in Pycharm IDE

This Project Consits of Drone and a laptop in which laptop is connected to drone via:WIFI and also controlled by Laptop.

The Drone Consists of a battery,4 propellers with guard.The Drone model is Tello-Mini Drone QuadCopter.

This has 13 minutes of flight time,Precise Hovering,5mp campera,Electronic image Stabilization,720p HD transmission,Multiple Flight Modes,Easy Operation,Programmable with the Tello SDK with this Tello SDK we connect this Drone to the Python code in the Laptop.

Project Content: 
1.Python Code
2.PyCharm IDE
3.Image Processing by Haarcascade method
4.Crack detection by Tello Drone
